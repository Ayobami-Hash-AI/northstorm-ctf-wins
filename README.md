# Operation Northstorm — CTF Wins

Team: Operation Northstorm, the BSides Ottawa 2026 competition — see the
[dragonforce-board](https://github.com/omaribrahim6/dragonforce-board) team repo
(`team.md`).

This repository documents the team's **wins**: the challenges the scoreboard
shows as solved. Wins are recorded by challenge id, name, phase, solver, date solved
and a short method summary. Flag strings themselves are not recorded here, per the
team rules ("never put a flag on the board or in git") — the scoreboard on the team
board records solves.
